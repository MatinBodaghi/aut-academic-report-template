# قالب رسمی طرح پیشنهادی و نامه‌نگاری اداری (AUT Official Proposal & Administrative Letter Template)

[![LaTeX XeTeX](https://img.shields.io/badge/LaTeX-XeTeX-blue.svg?logo=latex)](https://www.latex-project.org/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](../LICENSE)

این قالب برای نگارش **طرح‌های پیشنهادی (پروپوزال‌های اجرایی/دانشجویی)، نامه‌های رسمی درخواست اداری، درخواست فضا و امکانات، بودجه و رویدادها** در سطح دانشگاه صنعتی امیرکبیر (پلی‌تکنیک تهران) و دانشکده‌های تابعه طراحی و بهینه‌سازی شده است.

---

## 🏛️ ویژگی‌های طراحی و ساختار سند

این قالب شامل یک سند رسمی دو بخشی منسجم است:

1. **صفحه اول: نامه اداری رسمی روکش (Formal Cover Letter):**
   - **سربرگ سه‌بخشی اداری:** لوگوی رسمی دانشگاه صنعتی امیرکبیر و نام دانشکده در سمت راست، «بسمه تعالی» در مرکز، و تاریخ، پیوست و لوگوی دانشکده در سمت چپ.
   - **خطاب رسمی و موضوع:** تنظیم استاندارد نام مقام مخاطب، سمت و موضوع درخواست.
   - **فونت بزرگ‌تر و خوانا:** با قلم ۱۳ و فاصله خطوط باز جهت سهولت مطالعه و اختصاص فضای کافی در حاشیه برای **پاراف، دستور و هامش ریاست یا مسئولین محترم**.
   - **صفحه اول کاملاً تمیز:** فاقد شماره صفحه یا خطوط سربرگ اضافه (`\thispagestyle{firstpage}`).

2. **صفحات دوم به بعد: طرح پیشنهادی جامع پیوست (Detailed Attached Proposal):**
   - **سربرگ و پانویس اداری (`fancyhdr`):** عنوان مختصر طرح در سمت راست، نام دانشکده در سمت چپ، و شمارنده فارسی صفحات به فرمت `صفحه X از LastPage`.
   - **ساختار منطقی و توجیه‌پذیر ۹ مرحله‌ای:**
     1. *مقدمه و بیان مسئله* (توصیف دقیق خلاءها و چالش‌های موجود)
     2. *اهداف اصلی طرح* (تعیین اهداف راهبردی قابل سنجش)
     3. *محورهای اجرایی و برنامه‌های پیشنهادی* (برنامه‌های عملیاتی فازبندی شده)
     4. *ضرورت و توجیه طرح / فضای فیزیکی* (کاربردها و مشخصات فضا یا منابع درخواستی)
     5. *نقش اجرایی در توسعه فعالیت‌های دانشکده* (شرح وظایف و خدمات تشکل به عنوان بازوی اجرایی)
     6. *دستاوردهای مورد انتظار* (خروجی‌های ملموس برای دانشگاه و دانشجویان)
     7. *حمایت‌ها و امکانات مورد درخواست* (تفکیک دقیق به **الف) درخواست اصلی** و **ب) درخواست‌های تکمیلی**)
     8. *تعهدات مجریان طرح* (تعهدات قانونی در نگهداری، حفظ نظم، پاسخ‌گویی و گزارش‌دهی دوره‌ای)
     9. *جمع‌بندی و درخواست نهایی* (پیام نهایی موجز و امضای شورای تشکل)

## 📂 ساختار فایل‌های قالب

```text
proposal-template/
├── fonts/                 # فونت‌های استاندارد فارسی و لاتین (B Nazanin, B Titr, Times)
├── logos/                 # لوگوهای رسمی دانشگاه و دانشکده (aut-logo.png, EE-aut.jpg)
├── proposal-style.sty     # استایل و تنظیمات فنی بسته‌ها و زی‌پرشین
├── main.tex               # سند اصلی طرح پیشنهادی و نامه اداری (قابل ویرایش)
├── main.pdf               # پیش‌نمایش خروجی کامپایل‌شده (۶ صفحه)
└── README.md              # راهنمای استفاده و شخصی‌سازی
```

## ⚙️ نحوه شخصی‌سازی متغیرها (Quick Customization)

برای استفاده از این قالب برای موضوع یا دانشکدهٔ دیگر، کافی است متغیرهای ابتدای فایل [main.tex](main.tex) را مطابق نیاز خود تغییر دهید:

```latex
% مشخصات دانشگاه و دانشکده
\newcommand{\UniversityName}{دانشگاه صنعتی امیرکبیر}
\newcommand{\UniversitySubtitle}{(پلی‌تکنیک تهران)}
\newcommand{\FacultyName}{دانشکده مهندسی برق}

% مشخصات مقام مخاطب (گیرنده نامه)
\newcommand{\RecipientGender}{جناب آقای}  % یا: سرکار خانم
\newcommand{\RecipientName}{دکتر ...}
\newcommand{\RecipientTitle}{ریاست محترم دانشکده مهندسی برق}

% مشخصات فرستنده (انجمن علمی، ورزشی، شورا، کارگروه، دانشجو)
\newcommand{\SenderTitle}{انجمن ورزشی دانشجویان دانشکده مهندسی برق}
\newcommand{\SenderCouncilTitle}{شورای انجمن ورزشی دانشکده مهندسی برق}
\newcommand{\SenderShortTitle}{انجمن ورزشی}

% عنوان و موضوعات
\newcommand{\LetterSubject}{درخواست تخصیص فضای اداری اختصاصی به ...}
\newcommand{\ProposalTitle}{طرح پیشنهادی تخصیص فضای اداری به ...}
\newcommand{\ProposalDate}{\today}
\newcommand{\ProposalAttachment}{دارد (طرح پیشنهادی)}
```

## 🚀 روش‌های کامپایل

### روش ۱: استفاده از VS Code
1. فایل `proposal-template/main.tex` را در محیط VS Code باز کنید.
2. با فشردن کلیدهای `Ctrl + Alt + B` سند با استفاده از موتور `XeLaTeX` کامپایل می‌شود.
3. با فشردن `Ctrl + Alt + V` پیش‌نمایش زنده PDF را مشاهده نمایید.

### روش ۲: کامپایل از طریق ترمینال (Terminal / CMD / PowerShell)
در پوشهٔ `proposal-template` دستور زیر را اجرا کنید:

```bash
xelatex -interaction=nonstopmode main.tex
xelatex -interaction=nonstopmode main.tex
```

> **نکته:** جهت درج درست شماره صفحه نهایی (`LastPage`)، اجرای دو مرحله‌ای کامپایل توصیه می‌شود.
